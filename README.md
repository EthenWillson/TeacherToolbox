## 自动更新机制

| 环节 | 说明 |
|------|------|
| 更新检查 | 应用启动时向云端检查接口查询新版本（版本、灰度比例、是否强制、更新说明由服务端控制） |
| 下载方式 | 通过本仓库 Releases 资产差分下载（blockmap），仅下载增量部分，省流量 |
| 安装方式 | Windows 自动下载并安装；macOS 暂不支持自动更新（需开发者证书），请手动下载 |

## 项目简介

班主任的日常事务高度碎片化：学生档案、座位、值日、考勤、班费、宿舍内务、家校沟通、量化积分、成绩分析……这些工作往往分散在微信群、Excel、纸质表格里，难以沉淀与追溯。

班主任智能工作台把上述场景整合进一个统一的工作台：数据集中存储、各模块共享同一份数据源、跨端实时同步，并配套集中化的控制平面（版本灰度、激活码、配额）与桌面端自动更新。

## 核心特性

- **三端一致**：Web 端、手机web端、Windows 桌面端共用同一套数据与交互，随时随地可用。
- **模块齐全**：覆盖学生管理、班级事务、宿舍、考勤、值日、班费、作业、请假、成绩、家校沟通、问卷、仪表盘、安全特殊关怀等班主任工作全场景。
- **单一数据源**：学习小组、座位安排、量化积分等跨模块数据只保留一份，一次修改全端联动。
- **云端同步**：基于 Cloudflare D1（数据库）+ R2（文件）同步，离线可继续工作，联网后自动增量同步。
- **集中控制**：D1 作为控制平面，统一管理版本灰度 / 强制更新、激活码（一码一账号）、用户存储配额。
- **离线优先**：离线模式下禁用照片 / 文件上传（配置 + 主进程双重校验），R2 附件不计入配额，桌面端本地 SQLite 不受配额限制。
- **桌面自动更新**：基于 GitHub Releases + D1 `app_versions` 表，支持灰度、强制、版本号策略。

## 功能模块

### 学生管理
- 学生档案：基础信息、个人全景档案（成长轨迹一图总览）
- 学生分组 / 学习小组：两级结构、支持搜索、可从座位分布一键创建
- 学生异动：转学 / 退学等状态管理
- 学生评价、量化积分、奖励与惩罚登记、批量操作

### 班级事务
- 课程表：支持为每门课程指定教室
- 班委会干部管理
- 座位分布：支持传统行列排布与小组合作桌两种模式
  - 小组合作桌：圆形 / 多边形（五边形、六边形等）真实桌形
  - 黑板位置可在顶部 / 底部切换，桌椅与学生随之 180° 翻转
  - 学生姓名始终正位、完整显示
  - 每张桌子可独立设置边数、每边人数、旋转角度
  - 支持导出省墨黑白 PDF
- 班级基础信息

### 宿舍事务
- 寝室分配
- 内务卫生：星级评定（按满分 / 及格分）、多宿舍同时登记、扣分项预设、日历视图、宿舍专属详情页（周 / 月 / 学期卫生分数曲线）
- 查寝管理、规则设置

### 考勤与值日
- 日常考勤
- 离校台账（住校生离 / 返校）
- 值日安排与打卡

### 教学与成绩
- 作业管理
- 请假管理
- 成绩管理：成绩录入、分析与可视化

### 家校与沟通
- 家校沟通：通知、反馈
- 信息中心：展示看板、问卷调研（支持二维码收集）、赛事资讯
- 文案 / 速记：常用文案模板、随手速记

### 数据与看板
- 仪表盘：班级红线预警（处分预警、积分预警等）、待办汇总
- 日历：班级日程总览
- 工作管理：工作任务跟踪
- 成就 / 书签 / 道德活动 / 科目工具 / 智能助手等辅助模块

### 安全与特殊关怀
- 关爱台账、隐患排查、特异体质学生管理

## 常见问题

- **激活码区分大小写**，请按发放时的原样输入；未激活无法注册账号、无法同步云端数据
- **云端容量**：每个账号有独立存储额度，超限时仅拦截新写入，存量数据不受影响，删除冗余数据后自动恢复
- **离线模式**：数据仅存本地，不访问云端；离线模式暂不支持上传照片/文件
- **实时同步**：同一账号 Web 端与桌面端数据实时互通
